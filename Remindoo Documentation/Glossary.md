# Glossary

**Purpose:** Shared terminology used across Remindoo and this documentation (e.g. tenant, lead, proposal, SATR, MTD).

## "Chosen" (e.g. Chosen Email, Chosen Service)

When a template (Service Template, Email Template, etc.) is actually used to produce a real object on a client — e.g. an email template being used to create the real email for a specific client's service — the resulting real, instantiated object is referred to as a **"chosen"** version of that thing (a *chosen email*, *chosen service*, etc.), as opposed to the abstract template it came from. "Creating chosen emails" means instantiating the real emails for a client from Email Templates.


## Status vs Progress Status (Tasks)
**Status** is the simple state of a task (Not started, In-Progress, Awaiting Feedback, Complete, Archived, Snooze). **Progress Status** is the step the job has reached in the firm's workflow (e.g. Info Requested, Filed Externally, Accounts Approved But Invoice Pending), set by the service template.

## Internal vs External Deadline
**Internal Deadline** is when the firm's team should finish. **External Deadline** is the real statutory or client deadline (HMRC, Companies House).

## Token (Adjustable Token)
A placeholder written as ::Name:: (e.g. ::Lead Name::, ::Invoice Number::) that Remindoo replaces with the record's real value when an email is sent. **Preview Email** shows the result before sending; tokens it can't fill stay as written.

## Tenant
One firm's private space in Remindoo: its own clients, users, settings and data.

**Status:** Partially written.
