# Document Sharing Portal — Overview

**Purpose:** What the **Documents Portal** is for and what you can do with it.

The Documents Portal stores files for each client (and some leads) in folders, and controls which files the client can see in their client portal.

## The Documents page
- **All** and **Recent** views.
- **New Folder** and **Upload Files**.
- **Storage**: space used against your plan's limit, e.g. "472.6 MB / 3 GB · 15.38%".
- Columns: Name, Size, Date Added, Modified, Creator, and Client visibility (*Visible* means the client can see it in their portal).
- Folders are usually named after the client or lead, and can be created automatically when a service starts (set in the service template).

See also [Cross-Module Features](Cross-Module%20Features.md) for document requests sent from reminders.
