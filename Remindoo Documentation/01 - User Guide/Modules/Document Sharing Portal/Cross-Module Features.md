# Document Sharing Portal — Cross-Module Features

**Purpose:** How features owned by other modules (e.g. E-Sign, HMRC) show up for users while working inside **Document Sharing Portal**, with links out to their full documentation in `Features/`.

## Service Templates

Folders can appear here automatically, without anyone creating them by hand:

- Turning on **folder automation** on a Service Template means a folder is created here whenever that service is added to a client.
- Turning on a **document checklist** on a Reminder means that reminder can ask an external person to upload documents, which land in a folder here automatically.

See [Service Templates](../../Features/Service%20Templates.md).
