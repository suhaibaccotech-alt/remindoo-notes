# WhatsApp – Workflows

## Start a chat with a client
1. Go to **Inbox → WhatsApp** and click **New chat**.
2. Check **Sending from** is the right firm number.
3. Under **Find a client or lead**, type the name and pick the client.
4. Under **Send to**, pick one of the client's stored mobile numbers. The client must have a mobile number on a contact; add it in the client's Contacts first if needed.
5. If consent shows **Not recorded**, record it (see below).
6. Pick an **approved template**. A preview shows how it will read.
7. Click **Start chat**. You'll see "Chat started — the template is on its way" and the chat opens.

## Record WhatsApp consent
1. In New chat (or ⋮ → **WhatsApp consent** in an open chat), choose **Record an opt-in** (or **Record an opt-out**).
2. **How was consent given?** Signed engagement letter, Client portal, Web form, In person, By phone, By email, or Recorded by an admin.
3. Set the **date** consent was given.
4. Check the **wording** the client agreed to (UK service-messages wording, versioned).
5. Add an optional note and click **Record opt-in**. The number then shows "Consent: Opted in".

## Reply to a client
- Once the client messages you, the window shows **Open · 23h 59m** and counts down.
- While it's open, type a normal message and press send (or Ctrl+Enter).
- When it closes, the composer says "The 24-hour window has closed" and only shows approved templates.

## Use a quick reply
1. Click ⚡ in the composer.
2. Search or type the shortcut (for example `/test3`).
3. Click the reply. Tokens like `{{client_name}}` fill in from the client record.
4. If a token can't be filled, a **Check before you send** warning names it. Edit the message before sending. *(Currently the send isn't blocked, so check carefully.)*

## Organise chats
- **Star** a chat (☆ in the list or header) to find it under **Starred**.
- ⋮ → **Mark as unread** to come back to it later.
- ⋮ → **Archive** to move it to **Archived**.
- **Assigned** (+) to give the chat to a colleague. **Labels** (+) to tag it.

## Link a chat to a task or lead
- Click **Link task** and choose a task, or **Create new task** for a quick task.
- Click **Link lead** for prospects.

## See WhatsApp on the client record
- Open the client → **Conversation**. WhatsApp messages appear in the feed and in **Activity** with direction (Incoming/Outgoing), contact, and an **Open chat** link back to the inbox.
- *Currently you can't start a WhatsApp message from the client or task page. Use Inbox → WhatsApp → New chat.*
