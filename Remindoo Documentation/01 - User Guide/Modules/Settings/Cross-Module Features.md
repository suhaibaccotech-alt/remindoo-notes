# Settings — Cross-Module Features

**Purpose:** How features owned by other modules show up for users while working inside Settings, with links out to their full documentation in `Features/`.

## Service Templates

A Service Template you build here doesn't do anything on its own — it's only a blueprint. To actually use it:

- **Clients** — you apply the template to a client profile to create a real service (not yet documented).
- **Tasks** — the actual task(s) then get created automatically, following the deadline rules you configured (not yet documented).

Full picture: [Service Templates](../../Features/Service%20Templates.md).
