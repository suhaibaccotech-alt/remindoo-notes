# Getting Started

**Purpose:** A new user's first steps in Remindoo: logging in, finding your way around, and where things live.

## Logging in
1. Go to your firm's Remindoo address and enter your email and password on **Login Details**, then **Log In**.
2. If your firm has switched on two-step sign-in (MFA) for you, complete the extra step.
3. **Forgot password?** on the login page sends you a reset link.

## The main menu (left sidebar)
| Menu item | What it's for |
| --- | --- |
| **Dashboard** | Summary of your firm's work: tasks by stage, timesheets, capacity, leads, proposals, employee and client summaries. See [Dashboard](Modules/Dashboard/Overview.md). |
| **Leads** | Prospective clients before they sign up. See [Leads](Modules/Leads/Overview.md). |
| **Proposals** | Proposals and engagement letters built with the Document Builder. See [Proposals](Modules/Proposals/Overview.md). |
| **Tasks** | All work for your clients, created by hand or automatically from services. See [Tasks](Modules/Tasks/Overview.md). |
| **Clients** | Your client records, services, contacts, compliance details and invoices. See [Clients](Modules/Clients/Overview.md). |
| **Emails** | Your connected mailbox inside Remindoo. See [Email](Modules/Email/Overview.md). |
| **Documents Portal** | Shared folders and files for clients and leads. See [Document Sharing Portal](Modules/Document%20Sharing%20Portal/Overview.md). |
| **Knowledge Base** | Help articles. |
| **Financial Assistant** | AI assistant for financial questions. |
| **Invoices** | Raising, sending and tracking invoices and payments. See [Invoices](Modules/Invoices/Overview.md). |
| **Settings** | Firm-wide set-up: employees, teams, service templates, email templates and more. See [Settings](Modules/Settings/Overview.md). |

## The top bar
- **Select Module** + search: pick a module (e.g. Tasks, Leads, Clients) and type 3 or more characters to search inside it.
- **Your name and balance** (top right): opens your account menu with your AML balance, current plan, **Top Up Balance**, **Subscription**, **Billing History** and **Logout**.
- **What's new** (bottom of the page): recent product changes.

## Tables work the same way everywhere
Most pages are tables with the same controls:
- **Search** box on the left.
- **Column visibility** (grid icon): show, hide, reorder and freeze up to 5 columns.
- **Filters** (funnel icon): add conditions like *Status is In-Progress*. **Save & Apply Filter** lets you name and save the filter, or **Apply Without Saving**.
- **Saved filter views** (bookmark icon): re-apply a saved filter.
- **Show Kanban View**: switch some tables to a board.
- Sort and filter icons on each column header.
