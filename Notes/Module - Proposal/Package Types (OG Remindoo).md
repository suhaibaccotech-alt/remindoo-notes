Price Lists can be created and tied to any or all of the package types at once. It **COULD** even be possible to select multiple of the same type at the same time. Can also name them. However, they are tied to created packages, not templates.

Tax Rules can be created. Requires Name and Rate. Also has boolean for status, and a checkbox for whether it is the default tax rule.
