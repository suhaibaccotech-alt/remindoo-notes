These options should all be included as part of the editor, with the exception of Video.

The top "blocks" are visual elements that are meant to display or format the document.

The bottom blocks are inputs for the client/lead/recipient.

Service Table's Services are not added directly on the page using the editor. Instead, a small button shows up on hover and opens up a popup. This popup contains all of the services for the company, sorted into packages. Here, it is possible to see the SKU and Pricing for each service. Also, has a search bar and filter for sorting. 

Once a service is added, the description, price, quantity and subtotal amounts are shown for each service. The information is shown in a preordained format and can be edited like any other element in the editor, at this stage. It is also possible to move the table above or below the other elements in the editor. 

Sections(Headings) can be added to the table. Additionally, another service can be added.

It is also possible to edit various aspects of the table: 
	To enable checkboxes for a specific added service
	To make the quantity of that service editable

A total for pricing has to be shown at the end of the table. This total should include any discounts applied for this table, and a total including VAT, which is based on a percentage that is shown above the final total.

If the price for a service is edited, the subtotal in front of that service, the Total Including VAT, and the Total Excluding VAT has to be updated in real-time.
