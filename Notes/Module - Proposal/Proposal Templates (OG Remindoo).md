Default Templates and Custom Templates are the 2 types.

3 Default Templates exist. They can be edited or selected. Selection of a template redirects the user to the proposal creation section.

This is the dashboard for editing. This allows the user to add these items to the template just like in bubble by dragging the element to where you want on the page. It functions in the same vein as a column container or a wordpress editor.
Clicking on the Setting Button shows this menu from the left of the page:
![[Pasted image 20250514194026.png]]
![[Pasted image 20250514194042.png]]


The background colour input works in any way the user wishes. This is to say that you could write green and it selects a matching hexcode by itself. Writing a hexcode directly also works just as well. However, this is a limit to its ability to detect more niche shades with the word only (try burgundy). If it doesn't recognize the word, it defaults to #000000. If you rewrite "transparent", it goes back to transparent. However, it does not change the colour of the element added. It simply changes the colour of the background upon which it sits. The element's own background will forever remain white.

The height slider sits at "auto", starts at 10px and goes up to 1000px.

Hovering on an element shows these 4 options. Allows the user to Edit the element, Duplicate the element (For Dividers, the copy appears after skipping the next non-Divider element. For the rest, the copy appear right after the original element unless the next element is a divider. In that case, the duplicate will show up at the end of however many dividers are placed right after the original.), Edit the element (again), and Delete the element, from right to left, respectively. Clicking and holding the cursor on any part of an element including the buttons will allow the user to reposition the element below or above any element as all elements are stacked vertically.
