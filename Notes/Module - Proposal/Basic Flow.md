Templates are made in advance. These have the fully formatted contract and/or proposal, built with the document builder. 

These templates are selected to create **Documents**. 

These Documents have the actual document from the Template, they have recipients (Name, Email, Phone Number, and Company {Has to be imported from CH, Name, Job Title at the Company for that Recipient, Address, City, Postal Code, Country, State/Region})

The Recipient works in a similar way to contacts, with the recipient needing to be saved in the system for later use. This will be used later to turn into a client. 

Probably have to link leads to this.

After selecting the recipient for the email, the document delivery method can be specified, along with confirming the email where it will be sent. (Not majorly relevant to us, since we want this to be an in-app thing).

It allows the user to restrict access to the document. This can be used in lieu of a client portal, so that only the client can open the document from their end. 

Then, after this step has been completed, the user is allowed to edit the document template itself for final touches, or creating a whole new document if a template was not selected beforehand.
