Custom Task/Preset Task
	If a service is added to a client, and then a task is created automatically by the system, it is a preset task. If the task was created manually by a user by using the button above the tasks table, then it is a custom task. 
Recurring
	A preset task will be recurring by default, unless certain settings are changed for that particular service. A custom task can be made to be recurring during its creation. 
Billable
	This is a boolean present in all tasks, it doesn't not have an additional effect on anything else. 
Linked to a Client
	A preset task will be linked to a client by default, while a custom task can be linked to a client if it is a detailed custom task. 
Linked to an External/Internal Service
	A preset task will always be linked to an external service, while a custom task can be linked to an external service, or use an internal service template (different from a service) to import subtasks and checklists.
Status
	Not Started is the default status for a task. 
	Not Started, In-Progress, and Awaiting Feedback are regarded as active statuses. These are tasks that are currently being worked on. 
	A Completed Task is not meant to be worked on any longer, and is meant to be kept as historical record. 
	A Snoozed task will be worked on at a later date, but not right now. 
	An Archived task is simply on-hold, and is taken out of active work for various reasons.
Progress Status
	Custom Tasks do not have any functionality associated with progress status, other than being a marker for the present stage of working on this task.
	This mostly affects setting Deadlines, and Automated Reminders for Preset Tasks. When a specific progress status is set, the internal deadline is set to that date plus an offset. If the settings are set in such a way, the external deadline will also be set to the exact same date. Additionally, emails associated with this preset task will stop being sent if the current selected progress status is different from the assigned progress status to the reminder that contains the emails.
Internal Deadline
	This deadline is meant for internal control and monitoring, to ensure that employees finish their work ahead of time, for accountants. For non-accountants, this is simply the deadline for their assigned tasks.
External Deadline
	This deadline is the actual deadline for accountants as UK government agencies will impose penalties on the client if the work is not submitted by this date. For non-accountants, this is frequently left empty. 
Associated Reminder and Emails
	A preset task will have a reminder and emails associated with it, if the service template is created correctly. 
Task Timeline
	The standard events give basic historical data.
Subtasks
Comments (Task and Subtask)
	Comments can be associated with a specific subtask or with the overall task. These function in a similar way to notes in the Client timeline, to provide additional context and ongoing updates regarding dealings with the relevant client and/or the task itself.
Timer logs (Task and Subtask)
	The timer run on subtasks has a log for each specific subtask and for the overall task. 
Checklist
	These are used to ensure that all of the work related to a specific task has been completed. A preset task will have an associated checklist from its service template. A custom task can import a checklist during creation if it is a detailed custom task. There is no way to create a checklist after the task has been created. 
Client Timeline (Particularly Notes)
	Notes are the only event type that can be manually created in the client timeline. It is used by accountants to store additional information that is not included as a field in the system.
